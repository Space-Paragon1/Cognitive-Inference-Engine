The browser extension popup at 360 × 520: mini live gauge, context, breakdown, focus toggle and connection status.

Built from the `LoadGauge` mini ring, `ContextPill`, `Breakdown` (compact), `Toggle`, `Button` and `ConnectionStatus`.

## States
1. **Live, focus off**: an 84px ring with 62%, a Deep focus pill and confidence, the compact breakdown, a "Focus mode" toggle row and "Open dashboard".
2. **Focus mode on**: the toggle row becomes a progress card ("31 / 50 min", "Blocking 3 sites · notifications silenced") with "Stop focus".
3. **Not paired**: the logo, "Pair this browser", a pairing-code field and "Pair".

## Notes
Header: logo, name and a settings icon button. Footer: the Live status and "Sent 4s ago". The popup uses the same tokens and theme as the app. Follow the browser's colour scheme unless the student has chosen a theme in the app.
